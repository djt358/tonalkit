# tonekit P0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Rust tone-assessment library that runs on-device on iOS (Swift via UniFFI), with Python
bindings for the harness, a Mandarin pack and
an evaluation harness, carried far enough to run xiuzhen Gate 1 (S1) on DJ's recordings.

**Architecture:**
- `analyze()` computes f0, energy, syllable nuclei and boundary candidates once.
- `decode()` scores caller candidate sequences of any length with a segmental DP over
  log-likelihood ratios against a background model.
- `lattice()` gives an open-set tone lattice.
- `assess()` fuses the decode with external evidence into grading output.
- Languages and accents are data packs (TOML).

**Tech Stack:**
- Rust (stable ≥1.85, edition 2021), with crates `pyin` 1.2, `serde`/`serde_json`/`toml`,
  `thiserror`, `proptest`, `insta`, `approx`, `hound` + `clap` (CLI only).
- UniFFI (Swift, native iOS) and PyO3/maturin (Python harness).
- Python ≥3.11 with uv, `numpy`, `scipy`, `pydantic`, `pyworld`, `swift-f0` + `onnxruntime`,
  `pytest`.

**Spec:** `docs/superpowers/specs/2026-09-28-tone-assessment-design.md` (v2.2). §5 holds the
authoritative type definitions; this plan refers to it instead of repeating them.

**Repo:** new repository `tonekit/`. All paths below are relative to its root. Copy the spec and
this plan to `tonekit/docs/` in Task 1, and copy `docs/research/tone-assessment-license-register.csv`
to `tonekit/data-register.csv`.

## Global Constraints

- Every crate: `license = "MIT OR Apache-2.0"`; `#![forbid(unsafe_code)]` except `tonekit-ffi`
  and `tonekit-py`.
- `deny.toml`:
  - Allow MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, Zlib, Unicode-3.0.
  - Allow MPL-2.0 only for crates matching `uniffi*`.
  - Deny GPL, LGPL, AGPL and SSPL.
  - Ban `reqwest`, `hyper`, `ureq`, `rustls`, `native-tls`, `openssl`, `curl`.
- Core crates (`-core`, `-f0`, `-segment`, `-shape`, `-pack`, `-decode`, `-fuse`, `tonekit`) use
  no threads, filesystem, clock or randomness.
- **iOS-first, on-device:** `tonekit-ffi` builds for `aarch64-apple-ios` and
  `aarch64-apple-ios-sim`. P0 proves it on the iOS Simulator (Task 12). There's no wasm target.
- **Signal:**
  - Sample rate is exactly 16 000 Hz; anything else is `AssessError::UnsupportedSampleRate`.
  - `HOP = 160` (10 ms); frame i is centred at i·160 samples; frame count = `pcm.len()/160 + 1`
    for every track.
  - pYIN: frame 1024, fmin 50 Hz, fmax 600 Hz, centred framing with zero padding.
- **Pitch:**
  - Semitones re 55 Hz: `st = 12·log2(hz/55)`.
  - Chao: `1 + 4·(st − floor_st)/(ceil_st − floor_st)`, unclamped. `CONTOUR_POINTS = 10`.
  - Octave repair when a voiced frame differs >9 st from the median of up to 5 voiced neighbours
    on each side; shift ±12 st toward the median.
- **Register:**
  - Cold start = utterance p5/p50/p95 of voiced semitones with floor −2 st and ceil +2 st.
  - Cold while `n_syllables < 30`. Minimum `ceil − floor` is 4 st (expand symmetrically).
  - Merge weight `w = min(0.5, u/(n+u))`.
- **Issues:**
  - `Clipped` if >1% of samples have |x| ≥ 0.99. `LowSnr` if p95 − p10 of frame dB < 10.
  - `TooShort` if the voiced part is under 80 ms. Voiced frame = `hz.is_some()` (ruling R32; `voiced_p` is only a confidence weight).
  - Tolerance widen ×1.5 if any of `LowSnr`, `Clipped`, `ColdStartRegister`. Deltas suppressed
    under `LowSnr`.
- **Scoring (spec §7.1):** weights `w_k = max(voiced_weights[k], 0.25)`; inside an `unvoiced_ok`
  region, points with `voiced_weights[k] < 0.5` get `w_k = 0`. Onset and offset terms carry
  weight 0.5 each.
- **Decoding:** syllable segments 60–800 ms; gap edges only between consecutive boundaries;
  `dur(d) = −(ln(d/r))²/(2·dur_sigma²)`.
- **Seeds (`cmn.calib.json`):** temperature 1.0; β0 0.0, β_ac 1.0, β_tr 0.5, β_nn 0.0,
  veto_cap 0.05; filler_per_frame 0.03; unvoiced_syllable_llr −3.0; null_bias −2.0; dur_sigma
  0.4; default_rate_s 0.22. `heard_threshold` 0.6 (pack).
- **Segmentation seeds:** speech margin 10 dB over the p10 frame dB; nucleus dip 2 dB; minimum
  nucleus spacing 6 frames; energy smoothing 5-frame moving average; boundary cap
  `4·nuclei + 2`.
- **Schemas:** `"tonekit.lattice.v1"`, `"tonekit.assessment.v1"`. cmn tone ids are `"1".."5"`.
- **Data:** synthetic or TTS audio is never used to fit shipped calibration. Every shipped
  calibration file has a `PROVENANCE.toml` checked against `data-register.csv`.
- **Gate S1:** LOO-threshold CA ≥ 0.90 and WA ≤ 0.10 on the 20 gate pairs.

## Review Focus

1. **Extreme or unknown speaker range** (≈75 Hz low voice, ≈320 Hz high voice, no register
   given): contours must normalise to the same Chao shapes, and a cold start must widen
   tolerance, not fail. Pinned in Task 5 (`extreme_registers_normalize`) and Task 10
   (`cold_start_register_flags_and_widens`).
2. **Whisper or silence:** must produce `overall = None` and `NotMeasured`, never a wrong-tone
   verdict. Pinned in Task 10 (`whisper_is_not_measured`).
3. **Hesitation or extra syllable before the spell** (嗯 + 一杯水): the intended candidate still
   wins and its tones are not shifted by one. Pinned in Task 9
   (`leading_filler_syllable_does_not_shift_tones`).
4. **T3 creak dropout mid-syllable:** must not count against T3. Pinned in Task 7
   (`t3_creak_gap_not_penalized`).
5. **Very fast speech** (voiced < 80 ms per syllable): `Partial(TooShort)` with the contour term
   dropped, no panic, still ranked. Pinned in Task 5 (`short_syllable_partial`) and Task 7
   (`too_short_uses_endpoints_only`).

- [ ] **Step 3: Implement** (de Jong & Wempe-style).
  - **Nuclei:** local maxima of the 5-frame-smoothed dB inside the region that are ≥ threshold
    and voiced (periodic: `hz.is_some()` within ±2 frames, rulings R27/R32). Merge adjacent candidates when the minimum between them

    `voiced_p` crosses 0.5 ∪ interior local minima inside any inter-boundary span > 350 ms.
    Dedup within 2 frames (keep first). Cap per Global Constraints: keep edges and inter-nucleus
    minima first, then voicing edges by |Δvoiced_p|.
